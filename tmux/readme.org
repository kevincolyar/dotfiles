#+end_src

** On MacOS with Ghostty: Fix undercurls

Emacs 31 (and nvim, less, ...) only emits =SGR 4:3= / =SGR 58= -- curly and
colored underlines -- when the terminfo entry for =$TERM= advertises the
extended capabilities =Smulx= and =Setulc=. Upstream's =tmux-256color= entry
has neither, so inside tmux those faces silently degrade to a plain =SGR 4=.

Ghostty's =xterm-ghostty= entry does advertise both, so tmux already enables
its =usstyle= feature and forwards the sequences outward; only the inward
advertisement is missing. =terminal-overrides= cannot fix this -- it describes
the outer terminal, not what tmux reports to the pane.

#+begin_src sh
~/.dotfiles/terminfo/install.sh
#+end_src

That recompiles =~/.terminfo/74/tmux-256color= from the system entry with both
capabilities added. Verify:

#+begin_src sh
infocmp -x tmux-256color | grep -E 'Smulx|Setulc'
#+end_src

Existing tty frames cache terminal capabilities; restart emacs (or open a new
frame) afterwards.

In ~/.tmux.conf:

#+begin_src sh
set -g default-terminal "tmux-256color"
#+end_src
